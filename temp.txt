Descripción del Proyecto</h1><p>El proyecto integrador consiste en el desarrollo de una aplicación web de una sola página (SPA) denominada LasDosCaras, una plataforma cuyo objetivo central es presentar siempre las dos narrativas de cualquier tema: social, político, económico, cultural o de cualquier otra índole. La premisa es que ningún tema tiene una sola cara: LasDosCaras garantiza que el usuario vea ambas perspectivas de forma estructurada y equitativa, fomentando el pensamiento crítico y el debate informado. La aplicación consume un REST API con autenticación JWT ya provisto por el docente, el cual expone los endpoints necesarios para gestionar usuarios, publicaciones con dos perspectivas (temas), categorías, hashtags, comentarios, reacciones (likes/dislikes) y funciones de moderación para el rol de superadministrador.</p><p>El objetivo técnico del proyecto es integrar los conocimientos adquiridos en las cinco unidades del curso: arquitectura de aplicaciones web, HTML5/CSS3, JavaScript ES6+, un framework frontend con TypeScript, y la interoperabilidad con servicios REST externos. El producto final debe ser una aplicación funcional, responsiva, segura y bien estructurada, que refleje el concepto de LasDosCaras tanto en su funcionalidad (mostrar siempre ambas perspectivas) como en su diseño de interfaz, con historial de Git que evidencie la participación activa de todos los integrantes del equipo.</p><h1>2. Requisitos de Git y Trabajo en Equipo</h1><p>El proyecto debe desarrollarse en un repositorio GitHub compartido. La participación equitativa de todos los integrantes debe ser demostrable a través del historial de commits.
